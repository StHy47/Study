# 네트워크 

## 정의
  - 네트워크 = 컴퓨터 네트워크
  - 여러 장치 간 서로 정보를 주고 받는 통신망
### 인터넷
- 네트워크를 연결하는 네트워크

## 거시적 관점의 네트워크
### 네트워크의 기본 구조
- 네트워크의 구성 요소 : 노드, 간선, 메세지

  ### 그래프
  - 노드와 간선으로 구성된 자료 구조
  - 구성 요소 : 노드, 간선, 자료구조
    - 노드(node) = 정점(vertex)
    - 간선(edge) = 링크(link)
    - 자료구조 : 정보를 표현하고 다루는 방법
  </details>

- 노드 : 정보를 주고 받는 장치
    - 특별한 노드 : 호스트, 중간노드
- 간선 : 정보를 주고 받는 유무선 통신 매체
- 메세지 : 노드 간에 주고 받는 정보



### 호스트
- 노드 중 네트워크의 가장자리에 위치한 노드
  - 네트워크의 정보 최초 생성 및 송신, 최종 수신
- (= 종단 시스템)
- 특정한 역할을 수행하는 호스트의 종류
  - 서버
  - 클라이언트
 
#### 서버
- 어떤 서비스를 제공하는 호스트
  - 서비스 : 파일 서버, 웹 서버, 메일 서버 등

#### 클라이언트
- 서버에게 서비스를 요청(리퀘스트)하고 서버 응답(리스폰)을 제공받는 호스트
- **예시**
  - 클라이언트 : 내 컴퓨터
  - 요청 : 구글에 귀여운 마루 사진 검색
  - 응답 : 귀여운 마루 사진 짠~


### 네트워크 장비
- 중간노드 : 호스트 간 주고 받는 정보가 중간에 거치는 노드
- 예시
    - 이더넷 허브
    - 스위치
    - 라우터
    - 공유기
